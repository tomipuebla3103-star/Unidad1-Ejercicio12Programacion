 Control de Calidad en Línea de Producción

Descripción

Este ejercicio consiste en crear una clase en Java que represente una pieza industrial. Permite registrar sus medidas y comprobar si cumple con la longitud estándar establecida.

 Funcionamiento

* Registrar el código y las longitudes de la pieza.
* Validar que las medidas sean valores positivos.
* Comparar la longitud de la pieza con la longitud estándar.
* Verificar que la diferencia no supere los 0.5 milímetros permitidos.
* Mostrar por consola si la pieza es aceptada o rechazada.

Conceptos utilizados

* Clases y objetos.
* Encapsulamiento.
* Constructores.
* Métodos booleanos.
* Validaciones.
* Comparación de valores.

 Ejemplo

Se crean dos piezas industriales con distintas medidas y se utiliza el método `esAceptable()` para determinar si cumplen con el margen de tolerancia permitido.

Si la diferencia entre la medida de la pieza y la estándar es menor o igual a 0.5 milímetros, la pieza es aceptada. En caso contrario, es rechazada.
